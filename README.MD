## O que tem no notebook

Segue a estrutura do enunciado (M1.1 - Operações Pontuais e Filtragem Espacial):

1. Manipulação de pixels (cor mais frequente, mergeImage)
2. Manipulação de bits (BitQuantizeImage, planos de bits, lena1/2/3)
3. Questões teóricas + cálculo de baud rate
4. Equalização e transformação de histograma
5. Detecção de bordas (Canny, Roberts, Prewitt, Sobel, Laplaciano) com ruído
6. Filtragem high-boost
7. Filtragem bilateral
